# botforweb Marketing Website

The marketing website and interactive sandbox demo for botforweb, a secure, zero-hallucination documentation chatbot RAG SaaS.

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Interactive Sandbox**: [React](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styles**: Vanilla CSS

## Getting Started

### Prerequisites

- Node.js >= 22.12.0

### Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the local development server:
   ```bash
   npm run dev
   ```

### Other Scripts

- `npm run build` - Build the production-ready static site.
- `npm run preview` - Preview the built production site locally.
- `npm run astro check` - Run TypeScript and Astro diagnostics.
